# POL Density Profiles & Surface Patterns

## Density Profiles (Doc 56 §12)

### D1 — Spacious Commerce (Retailer)
- **Primary Audience:** Retailer shop owners, grocery managers.
- **Visual Thesis:** Clean, uncluttered, high-whitespace, large touch targets (min 44px), prominent search bar, unmistakable product images, bold pricing in Toman.
- **Specs:**
  - Control Y padding: 12px
  - Table / Card Row Y padding: 16px
  - Section Spacing: 24px–32px
  - Touch Target: >= 44px

### D2 — Balanced Operations (Vendor)
- **Primary Audience:** Wholesalers, warehouse dispatchers, vendor sales staff.
- **Visual Thesis:** Efficient table/list layouts, quick batch toggles, daily inventory stock confirmation, multi-currency / settlement summaries.
- **Specs:**
  - Control Y padding: 10px
  - Table / Card Row Y padding: 12px
  - Section Spacing: 20px–24px
  - Touch Target: >= 40px

### D3 — Dense Command (Operations & Admin)
- **Primary Audience:** Support agents, dispute adjudicators, catalog moderators, ops leads.
- **Visual Thesis:** Queue-first, exceptions-first, compact row height, persistent filters, high data density per viewport, keyboard navigable.
- **Specs:**
  - Control Y padding: 8px
  - Table / Row Y padding: 10px
  - Section Spacing: 16px–20px
  - Touch Target: >= 36px (desktop command)

### Mobile & Field Activator
- **Visual Thesis:** Bottom navigation bar, bottom action sheets, large sticky primary action, high contrast in daylight, network-aware offline indicator.
