# POL Mobile Visual QA Evidence

This directory is the durable evidence area for the real-Android visual baseline.

## Rules

- Screenshots must originate from a real Android runtime.
- No generated/mock/design screenshots are valid evidence.
- Every captured PNG requires existence/readability/dimension verification and SHA256.
- `manifest.json` is the machine-readable capture ledger.
- `VISUAL_QA_CAPTURE_LEDGER.md` is the human-readable run ledger.
- `MASTER_MOBILE_VISUAL_INVENTORY.md` is the current screen/state inventory.
- Capture Phase does not fix UI, refactor code, or run functional/regression QA.
