3. ARCHITECTURAL & LIFECYCLE CERTIFICATION
--------------------------------------------------------------------------------
- Lifecycle State Machines:
  * Orders: CREATED -> SUBMITTED -> ACCEPTED -> READY -> DISPATCHED -> DELIVERED / CANCELLED / REJECTED
  * Reservations: ACTIVE -> CONSUMED / RELEASED / EXPIRED (15-min TTL, atomic commit triggers)
  * Deliveries: ASSIGNED -> PICKED_UP -> IN_TRANSIT -> ARRIVED -> DELIVERED / FAILED
  * Disputes: OPEN -> INVESTIGATING -> RESOLVED / CLOSED (Orthogonal SSoT in disputes table)
  * Refunds: PENDING -> APPROVED -> COMPLETED (Actor separation: creator != approver)
  * Payments: PENDING -> INITIATED -> SUCCESS / FAILED / CANCELLED / REFUNDED (Non-custodial direct)
  * Settlements: PENDING -> CALCULATED -> RECONCILED / DISPUTED / CLOSED

- Invariants Enforced:
  * Strict Tenant Isolation: All routes enforce active user + active org + active membership.
  * Privilege Ceiling: Staff roles cannot be delegated owner-only privileges.
  * Audit Immutability: admin_audit_logs & inventory_audit_log reject client UPDATE and DELETE.
  * Outbox Reliability: All domain state transitions emit transactional outbox events with
    dedicated templates in notification_templates (076 verified).
