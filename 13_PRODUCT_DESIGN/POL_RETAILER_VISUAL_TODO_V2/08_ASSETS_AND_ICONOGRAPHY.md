# دارایی‌های تصویری، نمادها و قرارداد آیکون

## موجودی ساختاری فعلی

- JSON مستر Doory شامل ۱۲ صفحه و ۶۷۷ شیء است.
- هیچ شیء با type=image در این JSON ثبت نشده است.
- متن‌های شیء در چند صفحه از ایموجی برای نماد کالا و navigation استفاده می‌کنند؛ شمارش روی JSON فعلی ۷۷ متن‌شیء دارای ایموجی را نشان داده است.
- این شمارش دربارهٔ ساختار JSON است و به‌تنهایی دربارهٔ خروجی PNG یا ظاهر runtime داوری نمی‌کند.
- فایل‌های تصویری PNG در پوشهٔ images موجودند؛ این بسته تصاویر مورد تأیید کاربر را به‌عنوان خط مبنا حفظ می‌کند، نه اینکه آن‌ها را خودسرانه جایگزین کند.

## قواعد دارایی محصول

1. تصویر کالا باید از منبع مجاز و معتبر بیاید؛ نام برند/بسته‌بندی و ادعای محصول را جعل نکن.
2. اگر تصویر در دسترس نیست، placeholder سازگار با سیستم طراحی داشته باش؛ طرح محصول را به‌دلیل شکست شبکه بی‌ثبات نکن.
3. نسبت تصویر، crop، background، resolution و fallback در تمام کارت‌ها یکسان و قابل پیش‌بینی باشد.
4. تصاویر promotion نباید از نظر سلسله‌مراتب بر قیمت، واحد، موجودی یا CTA برتری پیدا کنند.
5. اگر تصویر محصول برای فهم ویژگی‌ها ضروری نیست، استفادهٔ هدفمند از تصویرسازی ممکن است قابل‌قبول باشد؛ تصمیم باید ثبت شود.
6. در تصویرسازی، تفاوت بصری کالاها باید قابل تشخیص باشد و برای محصول مالی/ایمنی اطلاعات نادرست نسازد.
7. عکس واقعی از روی وب بدون اجازه/منبع مجاز به عنوان asset تولیدی کپی نشود.
8. provenance و شرایط استفاده در صورتی که دارایی واقعی وارد شود ثبت شود.

## قواعد آیکون

- یک خانوادهٔ آیکون کانونی انتخاب کن و در ناوبری/عملیات هم‌زبان بمان.
- ایموجی برای محتوای بازاریابی ممکن است مفید باشد، اما نباید ناخواسته جایگزین نمادهای تعاملی و وضعیتی شود.
- آیکون‌های جهت‌دار در RTL باید طبق قواعد جهت آینه شوند؛ آیکون‌های غیردوجهتی مانند جست‌وجو، بارکد، دوربین و تنظیمات آینه نشوند.
- وضعیت تنها با رنگ/آیکون مشخص نشود؛ برچسب متنی نیز بده.
- اندازهٔ ضربه‌پذیری آیکون باید حداقل هدف لمس اطراف را رعایت کند؛ کوچک بودن glyph به معنی کوچک بودن target نیست.
- آیکون با معنی مبهم باید label/accessibilityLabel داشته باشد.

## قواعد تصویر و دسترسی‌پذیری

- برای تصویر محتوایی، توضیح جایگزین معنادار تعریف شود.
- تصویر صرفاً تزئینی از درخت دسترس‌پذیری کنار گذاشته شود.
- متن داخل تصویر برای اطلاعات مهم استفاده نشود مگر نسخهٔ متنی جایگزین داشته باشد.
- سایه/گرادیان روی تصویر نباید کنتراست نامناسب برای متن بسازد.
- عکس‌های محصول از حیث کشیدگی، وضوح و crop در Light/Night و اندازه‌های مختلف آزمایش شوند.
