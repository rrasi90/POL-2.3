# POL Brand & Visual Language

## Brand architecture
- Corporate: **POL / پُل**
- Retailer product: **POL Market / پُل مغازه‌دار**
- Vendor product: **POL Vendor / پُل بنکدار**
- Internal product: **POL Ops**
- Field product: **POL Field**

The visual system is shared; product surfaces vary by job-to-be-done, not by creating unrelated brands.

## Brand attributes
1. Reliable
2. Fast
3. Practical
4. Transparent
5. Local-market aware
6. Technologically credible without looking corporate-heavy

## Visual direction
The system should combine a strong primary brand color with neutral operational surfaces and semantic status colors. The precise palette must be validated for Persian readability and contrast before token lock.

## Imagery
- Retailer: real shop / shelf / restocking context.
- Vendor: warehouse/catalog/order operations.
- Corporate: network, connectivity, trade infrastructure.
- Avoid generic stock imagery when it obscures the actual workflow.

## Iconography
Use a coherent stroke system, consistent optical weight and clear metaphors. Icons never carry critical meaning without text or status semantics.

## Tone of interface copy
- concise;
- respectful;
- operational;
- non-technical;
- Persian-first;
- no exaggerated claims.

## Brand guardrails
Do not use promotional language that contradicts evidence/hypothesis governance. UI copy must not promise savings, delivery time or stock availability that the system cannot substantiate.

## 2026-09-20 RTL/LTR Typography Rule — Parentheses

در UI فارسی، از استفاده ترکیبی و غیرضروری از پرانتز برای عبارت‌های دو زبانه اجتناب شود، زیرا در متن‌های Bidirectional ممکن است ترتیب بصری پرانتز و متن LTR/RTL مبهم شود.

قاعده ترجیحی:
- عنوان فارسی در یک line و اصطلاح انگلیسی در line/element جداگانه
- یا عنوان فارسی — English Term با عنصرهای مستقل
- برای status, SKU, code و numeric values از span/element مستقل با direction مناسب استفاده شود
- پرانتز فقط زمانی استفاده شود که از نظر معنایی ضروری باشد و سپس rendering واقعی RTL/LTR بررسی شود.
