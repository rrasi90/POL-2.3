## ۱. معرفی الگوی پایه

این الگو یک نقطهٔ شروع پایدار، توسعه‌پذیر و کاملاً استاندارد برای طراحی صفحات جدید اپلیکیشن مغازه‌داران، پنل‌های بنکداران، یا پروژه‌های مشابه B2B در محیط Doory است.

الگو شامل موارد زیر است:
۱. **صفحهٔ راهنمای سیستم طراحی:** تمام توکن‌های رنگی، مقیاس تایپوگرافی وزیرمتن و اندازه‌ها.
۲. **صفحهٔ کتابخانهٔ اجزای مرجع:** دکمه‌های اصلی و فرعی، فیلدها، شمارنده‌ها، بج‌های وضعیت، پیام‌های موفقیت/خطا و نوار ناوبری.
۳. **صفحهٔ قالب پیش‌فرض موبایل:** اسکلت‌بندی استاندارد ۳۹۰×۸۴۴ با نوار وضعیت سیستم، حاشیه‌های امن و نوار پایین.

## ۲. روش استفاده و ساخت پروژهٔ جدید از روی الگو

### روش الف) از طریق رابط کاربری Doory (توصیه‌شده)
۱. وارد آدرس محلی Doory شوید: `http://localhost:5173/login`
۲. با حساب کاربری آزمون پل وارد شوید:
   - **ایمیل:** `pol.test@local.dev`
   - **رمز عبور:** `Pol-Test-2026!`
۳. به بخش **قالب‌ها (Templates)** یا داشبورد مراجعه کنید.
۴. قالب **«الگوی پایه اپلیکیشن موبایل پل»** را انتخاب کرده و بر روی **«استفاده از این قالب» (Use Template)** کلیک کنید.
۵. یک پروژهٔ طراحی جدید مستقل در حساب شما ایجاد می‌شود که می‌توانید بدون نگرانی از خراب شدن الگوی مرجع، آن را ویرایش و نام‌گذاری کنید.

### روش ب) کپی مستقیم از طریق پایتون / API
برای تکثیر خودکار پروژه با یک اسکریپت ساده:

```python
import json
from pathlib import Path
from apps.designs.models import Design
from django.contrib.auth import get_user_model

User = get_user_model()
user = User.objects.get(email="pol.test@local.dev")

template_file = Path(r"C:\Users\rrasi_oorj8fq\Documents\پل\طراحی\نسخه-۰۱\الگوی_پایه_پروژه_پل.json")
data = json.loads(template_file.read_text(encoding="utf-8"))

# ایجاد پروژه جدید
new_design = Design.objects.create(
    title="پل | پروژه آزمایشی جدید",
    owner=user,
    width=390,
    height=844,
    preset="mobile-app",
    document=data["document"],
    page_count=len(data["document"]["pages"])
)
print("طرح جدید با شناسه ایجاد شد:", new_design.id)
```

## ۳. راهنمای سفارشی‌سازی (Customization)

### ۳٫۱. تغییر پالت رنگی (Branding Colors)
در صورتی که قصد دارید رنگ اصلی برند را تغییر دهید (مثلاً از `#246BFD` به رنگ سازمانی دیگر):
- در فایل JSON یا در ادیتور، تمام کدهای هگز `#246BFD` را با رنگ اصلی جدید جایگزین کنید.
- رنگ پس‌زمینهٔ دکمه‌های اصلی و نوار بالای صفحه به طور خودکار به رنگ جدید تغییر خواهد کرد.
- همواره کنتراست رنگ جدید با متن سفید را بررسی کنید که کمتر از `4.5:1` نباشد.

### ۳٫۲. افزودن صفحات تازه
برای اضافه کردن یک صفحهٔ جدید به پروژه:
۱. در ادیتور Doory بر روی دکمهٔ **«+ Add page»** در پایین بوم کلیک کنید.
۲. به صفحهٔ **«اجزای مرجع» (Reference Components)** بروید.
۳. اجزای موردنظر (نوار وضعیت، هدر، کارت محصول، دکمهٔ CTA و نوار پایین) را انتخاب کرده و کپی (`Ctrl+C`) کنید.
۴. در صفحهٔ جدید الصاق (`Ctrl+V`) کنید.
۵. نام صفحه را در نوار پایینی ادیتور به زبان فارسی تغییر دهید (مثلاً «پیگیری سفارش»).

## ۴. استانداردهای عدم شکست طراحی در پروژه‌های آینده

- **قانون طلایی متن:** هرگز `charSpacing` المان‌های متنی را تغییر ندهید (`"charSpacing": 0` الزامی است).
- **قانون جهت:** همواره ویژگی `"direction": "rtl"` را برای تمام تکست‌باکس‌ها فعال نگه دارید.
- **قانون ارقام:** هنگام ورود قیمت‌ها و ارقام، حتماً از اعداد فارسی (`۰۱۲۳۴۵۶۷۸۹`) استفاده کنید.
- **تفکیک لایه‌ها:** از ادغام متن با تصویر خودداری کنید تا لایه‌ها همیشه مستقلاً قابل ویرایش بمانند.
